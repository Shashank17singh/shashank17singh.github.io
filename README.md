# Shashank Singh — Portfolio

The source for my personal portfolio, built to present my work in AI engineering, machine learning, full-stack development, and systems programming.

**Live site:** [shashank17singh.github.io](https://shashank17singh.github.io/)

## Highlights

- Responsive, dark-themed single-page portfolio
- Hero, about, skills, experience, and project sections
- Animated interface details powered by Framer Motion and Tailwind CSS
- Direct links to GitHub, LinkedIn, and email

## Tech stack

- [Next.js](https://nextjs.org/) 16 with React 19 and TypeScript
- [Tailwind CSS](https://tailwindcss.com/) 4
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide](https://lucide.dev/) icons

## Project structure

```text
.
├── next_portfolio/        # Next.js portfolio application
│   ├── src/app/           # Page, layout, and global styles
│   ├── src/components/    # Portfolio sections and reusable UI
│   └── package.json       # App scripts and dependencies
├── api/                   # Legacy backend experiments
└── README.md
```

## Run locally

```bash
cd next_portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Useful commands:

```bash
npm run lint
npm run build
npm run start
```
