# Shashank Singh - Personal Portfolio

[![Live Demo](https://img.shields.io/badge/Live-Website-success?style=for-the-badge&logo=vercel)](https://shashank17singh.github.io/)

Welcome to the source code of my personal portfolio website! This repository hosts the front-end code that powers [shashank17singh.github.io](https://shashank17singh.github.io/), where I showcase my professional experience, skills, and featured software engineering projects.

## About the Portfolio

The portfolio is designed to be a clean, modern, and highly responsive platform to display my technical capabilities, ranging from systems programming in C++ to building full-stack AI/ML pipelines and agentic applications. 

### Key Features
- **Responsive Design**: Fluid layout that scales elegantly across mobile, tablet, and desktop viewports.
- **Project Showcase**: A detailed grid highlighting my best projects, complete with technology stack pills, GitHub links, and live demonstration links.
- **Dynamic Interactions**: Features scroll-reveal animations and interactive hover states for a polished user experience.
- **Dark-Themed UI**: A modern, dark-mode aesthetic utilizing CSS variables for consistent theming and easy maintenance.

## Technology Stack

This website is built with core web technologies, intentionally avoiding heavy frameworks to ensure maximum performance and fast load times:
- **HTML5**: Semantic structuring of content.
- **CSS3**: Custom styling, CSS grid/flexbox layouts, animations, and responsive media queries.
- **JavaScript (Vanilla)**: DOM manipulation, smooth scrolling, and scroll-reveal intersection observers.
