04 — Projects

Things I've built

Project 01
VectorDB — Vector Database from Scratch
A vector database built from scratch in C++, implementing HNSW, KD-Tree, and Brute-Force search side-by-side across 3 distance metrics (cosine, Euclidean, Manhattan), with a benchmark endpoint contrasting HNSW's O(log N) graph search against brute-force O(N) at scale. Wraps a full local RAG pipeline via Ollama — chunking documents into overlapping 250-word segments, embedding them with nomic-embed-text (768D), and retrieving context for a local LLM (Llama 3.2) to answer questions grounded in the uploaded data. Exposes a complete REST API (insert, delete, search, benchmark) built on cpp-httplib, paired with a web frontend that renders a live 2D PCA visualization of the vector space.
C++ HNSW KD-Tree RAG Ollama cpp-httplib HTML/CSS/JS

Project 02
Conversational RAG Chatbot with PDF Upload & History
A Retrieval-Augmented Generation (RAG) web app built with Streamlit, LangChain, and Groq. Users can upload one or more PDFs and hold a multi-turn conversation with their content — a history-aware retriever reformulates follow-up questions using the chat history for accurate, context-aware answers. Documents are chunked, embedded with HuggingFace's all-MiniLM-L6-v2, and indexed in ChromaDB for semantic search, with Groq's Llama 3.3 70B Versatile model powering fast inference. Supports multiple isolated chat sessions.
Python Streamlit LangChain Groq ChromaDB HuggingFace
