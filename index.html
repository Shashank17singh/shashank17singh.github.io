Vector Search Engine
Your-Own-AI — Vector Database from Scratch
A vector database built from scratch in C++, implementing HNSW, KD-Tree, and Brute-Force search side-by-side across 3 distance metrics (cosine, Euclidean, Manhattan), with a benchmark endpoint contrasting HNSW's O(log N) graph search against brute-force O(N) at scale. Wraps a full local RAG pipeline via Ollama — chunking documents into overlapping 250-word segments, embedding them with nomic-embed-text (768D), and retrieving context for a local LLM (Llama 3.2). Exposes a complete REST API paired with a live 2D PCA visualization frontend.

RAG Application
Conversational RAG Chatbot
A Retrieval-Augmented Generation web app built with Streamlit, LangChain, and Groq. Users upload one or more PDFs and hold a multi-turn conversation with their content — a history-aware retriever reformulates follow-up questions using chat history.
